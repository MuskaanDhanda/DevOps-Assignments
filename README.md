# DevOps Assignments

| 3 | Ansible | [Ansible Assignment](Ansible_Assignment.pdf) | 3-node Ansible cluster; playbooks installing Java and MySQL |
| 4 | Jenkins | [Jenkins Assignment](Jenkins_Assignment.pdf) | Jenkins master/agent setup on AWS EC2 |
| 5 | Kubernetes | [Kubernetes Assignment](Kubernetes_Assignment.pdf) | Deploying a 3-node Kubernetes cluster |

**Tools:** Git, GitHub, Docker, Ansible, Jenkins, Kubernetes, AWS EC2, Linux (Ubuntu)
